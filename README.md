# 고양이 점프샷

담 위에서 우물쭈물하던 고양이가 뛰는 순간 셔터를 눌러, 웃기고 귀여운 점프샷을 건지는 반응속도 게임입니다.

이 저장소는 기획서 v0.1의 플레이 가능한 브라우저 프로토타입입니다. 한 판은 5컷이고, 점수는 반응시간(ms) 하나입니다.

## 실행

```bash
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8765` 를 엽니다.

## 조작

고양이가 실제로 옆으로 뛰는 순간 화면을 터치합니다. 너무 이르면 허공 컷, 빠르면 프레임 한가운데의 점프, 늦으면 꼬리만 남습니다. 스페이스바로도 셔터를 누를 수 있습니다.

- 스테이지 클리어: 5컷 중 3컷 성공
- 별: 평균 260ms 이하 3개, 400ms 이하 2개, 클리어하면 1개
- 다음 챕터: 이전 챕터 별 8개
- 무한 모드: 거실 5스테이지 클리어. 실패 3번. 기록은 성공 컷 수
- 70ms 미만은 사진으로 남지만 랭킹에는 오르지 않습니다

## 기획서와의 차이

출시 목표는 Unity, iOS, Game Center, AdMob, Unity IAP입니다. 여기서는 그 루프를 브라우저에서 먼저 확인합니다.

- 고양이 이름: 치즈, 콩, 구름, 밤톨. 기획서에서는 미정이었습니다.
- 랭킹, 광고, 결제는 이 브라우저 안에만 저장되고 실제 스토어와 연결되지 않습니다.
- 광고를 불러오지 못하면 보상을 주지 않고 게임을 막지 않습니다.
